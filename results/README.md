# Resultados agregados públicos

Esta carpeta contiene únicamente salidas agregadas del simulador que pueden reproducirse a partir de `config/model_params.json` y el código público.

- `scenarios_aggregated.csv`: cinco escenarios, incluido el caso base.
- `sensitivity_aggregated.csv`: sensibilidad conjunta de los coeficientes beta al 90%, 100% y 110%.

No deben añadirse aquí exportaciones de registros, muestras empresariales ni resultados que permitan reidentificar personas.
