# Política de datos

Los 23 datasets utilizados por el piloto proceden de un entorno empresarial restringido y **no se publican**.

El repositorio público debe contener únicamente:

- código de perfilamiento y simulación;
- estructuras y contratos de datos;
- métricas agregadas;
- parámetros versionados;
- datos sintéticos demostrativos que no repliquen personas ni registros reales.

No publicar archivos fuente, muestras de registros, PII, credenciales ni exportaciones internas del EDA.

La pseudonimización reduce riesgo, pero no equivale a anonimización. Por ese motivo, una copia pseudonimizada de datos reales tampoco se considera automáticamente apta para publicación.
